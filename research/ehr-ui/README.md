# EHR UI research: Epic and athenaOne

Research into how Epic and athenahealth design their EHR screens, to take inspiration for CareOS components.
Patterns and ideas only: no vendor screenshots, logos or other assets are stored in this repository.

| File | What it is |
|---|---|
| [epic.md](./epic.md) | Epic Hyperspace / Hyperdrive, ambulatory, inpatient, mobile and MyChart: layout, screens, components, criticism, 36 public sources |
| [athenahealth.md](./athenahealth.md) | athenaOne (Clinicals, Collector, Communicator, mobile, patient app) and athenahealth's **Forge** design system, 50 public sources |
| [gap-analysis.md](./gap-analysis.md) | Every pattern mapped to CareOS components: have / partial / missing, plus a priority shortlist |

## How to review

1. Read the **gap analysis** first: it is the decision document.
2. Open the **source catalogs** (section 5 of each report) in a normal browser. Sources marked "screenshots" (training
   PDFs from health systems, iorad walkthroughs, App Store galleries) and the YouTube demos show the actual screens.
3. Mark which patterns to build; the shortlist at the end of the gap analysis is a proposal.

## Method and limits

- Built on 2026-10-10 from public sources only (health-system training booklets and tip sheets, vendor help pages and
  blogs, published design-system documentation, portfolios, review sites, YouTube listings).
- The research environment could not open the pages or videos themselves (network policy), so findings come from search
  summaries of those pages. Each finding carries a confidence tag in the reports. Nothing was invented; uncertain items
  are marked.
- Epic and athenaOne are configured per organisation: colours and labels vary by site. Treat them as patterns, not specs.

## Screenshots

Vendor screenshots are not stored here because this repository is public and both vendors' screens are copyrighted
(Epic in particular restricts sharing them). To build a visual reference board, capture them into a **private**
location (a private repository or shared drive) from the sources listed in the catalogs.
