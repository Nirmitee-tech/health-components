# Typography

Roboto from Google Fonts (400, 500, 700), as every screen loads it; Roboto Mono for codes; Brush Script MT for typed signatures. Body is `body` 14/20. Page titles `h1` 20/26 500; card titles `h2` 16/22 500; labels `label` 13/18 500; help and errors `helper` 12/16; sidebar group labels and stat labels `overline` 11px 700 uppercase. Stat numbers `kpi-value` 24px 500. Kiosk headings `kiosk-title` 24px.
